# stock-cli

A 股尾随止损命令行工具。输入股票代码，根据近 6 个月波动给出**建议回撤阈值**，默认采用该建议值计算**当前止损线**（可用 `-t` 指定固定百分比）；触及止损线时输出完整**心理过程拆解**与**执行纪律**。

数据行情来自 [stock-api](https://github.com/zhangxiangliang/stock-api)，历史 K 线来自东方财富公开接口。

## 安装

需要 Node.js >= 18。本目录位于 blog 仓库根目录。

```bash
cd stock-cli   # 从 blog 仓库根目录
npm install
npm run build
npm link   # 可选：全局命令 stock
```

或：

```bash
npm install -g .
```

## 用法

```bash
stock <code> [选项]
```

| 选项 | 说明 |
|------|------|
| `-t, --threshold <n>` | 采用回撤阈值 %；`0`（默认）= 采用建议阈值 |
| `--months <n>` | 回看月数，默认 `6` |
| `-a, --advice` | 强制输出完整心理拆解与执行规则 |
| `--json` | JSON 输出 |
| `-h, --help` | 帮助 |

### 示例

```bash
stock 600519
stock SH510500
stock 300308 -t 20
stock 600519 -a
stock 600519 --json
```

## 规则摘要

1. **建议阈值**：根据近 6 月最大单日/周/两周回撤，结合 ETF/热门板块分类，落在 8–12% / 12–18% / 18–25% 区间。
2. **止损线**：`阶段最高收盘价 × (1 - 采用阈值)`，最高价随行情上移，止损线只升不降。
3. **触发后**：现价 ≤ 止损线时，输出「心理过程拆解」与三条执行铁律（触发即卖、分两次卖限 1 交易日、卖出后冷却两周）。
