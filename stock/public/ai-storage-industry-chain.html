AI 算力存储产业链深度研究

本页聚焦 AI 数据中心「三层存储架构」——HBM（高带宽存储器）工作内存、DDR5/SOCAMM（小型可插拔内存模块）扩展内存、NVMe SSD（非易失性内存主机控制器接口规范固态硬盘）持久存储——从成本结构、产能错配、技术路线与国内外上市公司映射，拆解 AI 算力浪潮下的存储超级周期。

四锚点摘要

  • 行业：半导体存储（DRAM/HBM/NAND/SSD），周期属性强，AI 算力驱动结构性供需错配
  • 论文：Microsoft Research《Managed-Retention Memory: A New Class of Memory for the AI Era》（arXiv:2501.09605 / HotOS'25）
  • 热点：HBM4 量产、存储超级周期、原厂产能向 HBM 倾斜、国产替代窗口、Rubin 机架内存占比跃升
  • 产业链：晶圆制造 → HBM 封装（TSV/CoWoS）→ 模组/控制器 → 企业级 SSD → 数据中心集成

阅读口径

  • 「AI 服务器存储 TCO（总拥有成本）占比」按单台/单机架硬件采购价值理解，不等同于存储原厂制造成本或 bit 均价。
  • HBM 占 GPU 模组 BOM 约 40%-60%（随代际与容量变化），但整机视角下 GPU 子系统仍占 75%-85%；Rubin 代际内存独立占比显著上升。
  • 设备、材料、EDA（电子设计自动化）成本通过晶圆与封装价格间接进入存储 BOM，不强行塞进单机存储占比。
  • A 股映射区分「原厂/模组/控制器/分销/封测」；未上市龙头（长鑫、长江）以产业地位描述，不臆测 IPO 后估值。

论文要点与产业映射

论文：Managed-Retention Memory (MRM) · Microsoft Research（Legtchenko 等）· arXiv:2501.09605 · 2025-01 · HotOS'25

  • 核心结论：LLM（大语言模型）推理中 HBM 约一半存模型权重、一半存 KV Cache（键值缓存）；HBM 在写性能与小随机访问上过度配置，在密度、读带宽、能效上不足。作者提出 MRM（Managed-Retention Memory，托管保持内存）新存储类别——放宽长期数据保持要求（小时级即可），换取更高读吞吐、更好能效与单位容量成本。
  • 方法与数据：基于 Foundation Model 推理 workload 的 IO 模式分析；对比 HBM、DRAM、SCM（Storage Class Memory，存储级内存）各指标 trade-off；MRM 可让 STT-MRAM、ReRAM、PCM 等原 SCM 技术重新具备 AI 推理场景可行性。
  • 成本/效率启示：若 MRM 落地，AI 推理集群可在 HBM 旁引入第二内存层，降低 HBM bit 需求与单 token 推理能耗；利好新型非易失内存材料、CXL（Compute Express Link，计算快速链路）扩展与内存控制器创新；对 HBM 原厂短期是互补而非替代。
  • 产业验证状态：实验室/架构提案 — HotOS'25 论文级，尚无大规模商用部署；Intel Optane 已停产，MRM 路线需 3-5 年验证。
  • 投资映射：中长期关注 CXL 内存扩展（澜起科技等）、PIM/NMP（Processing/Near-Memory Processing，存内/近存计算）；短期 HBM 仍是唯一可量产方案，MRM 不改变 2026-2027 供需格局。

补充参考：Stratum 系统（Mono3D DRAM + NMP，arXiv:2510.05245）提出 MoE（Mixture of Experts，混合专家）模型 serving 的 HBM 替代架构 — 学术阶段，与 Rubin 量产 HBM4 路径并行存在。

  • 2026-03 · NVIDIA GTC：美光宣布 HBM4 36GB 12H 量产、192GB SOCAMM2 量产、9650 PCIe Gen6 企业级 SSD 量产，面向 Vera Rubin 与 BlueField-4 STX 架构。官方发布
  • 2026-Q1 · 合约价暴涨：TrendForce/行业口径交叉显示 DRAM 合约价 QoQ 约 +53%-95%、NAND 约 +33%-80%；AI 服务器出货量 YoY 约 +45%，存储产量增速领跑工业门类（工信部口径存储芯片产量 YoY +40%+）。
  • 2026-05 · 产能结构性收缩：三星 NAND 晶圆投片从 2025 约 490 万片降至约 468 万片；SK 海力士 NAND 从约 190 万降至约 170 万；两大厂合计减产约 6.2%，进一步收紧通用 NAND 供给。
  • 2026-05 · 国产龙头 IPO 进程：长江存储控股完成 IPO 辅导备案；长鑫科技 IPO 预期带动设备/材料/封测链资本关注。公开备案
  • 政策 · 国产替代：大基金三期、地方存储产业集群（武汉「世界存储之都」等）；行业目标 2027 存储自给率从约 15% 提升至约 40%（多方研报口径，政策导向）。
  • 出口管制：美国 BIS 对先进节点/HBM 设备与技术的限制，受控市场先进存储成本溢价约 25%-35%（Nomura 等机构估算区间）。

成本总览 · AI 数据中心存储产业链树

  • 0. AI 加速系统存储 TCO 总览 三层架构 100%
    • Tier-1 · HBM 工作内存 GPU 模组约 40%-60%；Rubin 机架约 15%-18%：模型权重 + KV Cache 驻留；带宽决定推理吞吐上限。H200 单卡 141GB HBM3e / 4.8TB/s；Rubin 单卡 288GB HBM4。ASP（平均销售价格）远高于 DDR5，毛利率原厂可达 50%+（景气上行期）。
    • Tier-2 · 主机内存（DDR5 / SOCAMM / LPDDR5X） 8 卡服务器约 2%-4%；Rubin 机架约 8%-10%：CPU 侧数据缓冲、分布式训练参数同步、Rubin 平台 SOCAMM2 低功耗高容量扩展（192GB-256GB/模块）。DGX H200 标配约 2TB DDR5；VR200 约 54TB LPDDR5X（36 CPU × 1.5TB）。
    • Tier-3 · 企业级 NVMe SSD 单机约 1%-3%；集群数据湖 TCO 显著放大：训练数据集、Checkpoint（检查点）、向量库、日志与冷数据。DGX H200 约 30TB NVMe；Gen6 SSD（美光 9650）顺序读约 28GB/s、随机读约 550 万 IOPS。QLC（四层单元）大容量 SSD 替代 HDD（硬盘驱动器）趋势加速。
    • Tier-4 · 网络存储 / 数据湖 集群 TCO 约 10%-20%（随规模）：60TB+ 大容量 NVMe、分布式文件系统；训练数据预取与 checkpoint 恢复瓶颈常出现在存储 IO 而非算力。
    • 间接成本摊入 通过晶圆/封装传导：TSV（Through-Silicon Via，硅通孔）设备、CoWoS（2.5D 封装）产能、ABF 载板、DRAM/NAND 刻蚀与沉积设备 — 影响 HBM 与 SSD 交付周期，不单独出现在终端 BOM 分项。
  • 1. HBM 产业链 AI 存储价值最高环节
    • DRAM 晶圆 HBM 成本约 50%-65%
      • SK hynix（SK 海力士） 法说会/公告 HBM 市占约 50%+，HBM3E/HBM4 领先；2026 产能基本售罄，LTA（长期协议）锁定大客户。
      • Samsung（三星电子） 官方 HBM3E Qual 进度曾落后，2026 加速 HBM4 追赶；存储综合龙头，DRAM+NAND+HBM 产能调配灵活。
      • Micron（美光科技） GTC 2026 HBM4 36GB 12H 2026Q1 量产；Rubin 平台 SOCAMM2 + Gen6 SSD 全栈绑定 NVIDIA。
    • HBM 封装（TSV + 堆叠 + CoWoS） HBM 成本约 25%-35%
      • TSMC（台积电） CoWoS 产能 GPU + HBM 2.5D 封装核心；CoWoS 产能是 HBM 交付瓶颈之一。
      • Amkor / SPIL 产业研究 OSAT（外包封测）分担部分 HBM 封装产能。
      • A股 封测链 通富微电 / 长电科技 先进封装产能扩张，HBM 封测国产化推进中；尚未确认进入 NVIDIA HBM 核心供应链。
    • 国产 HBM 待验证
      • 研发阶段 长鑫存储 / 武汉新芯等 HBM2/HBM3 研发与验证中，良率约 60% vs 国际 90%+；2027 前难规模供货国际 AI 平台。
  • 2. DRAM / 利基型存储 产能错配受益环节
    • 通用 DDR5 / 利基 DRAM 模组毛利率弹性高
      • SK hynix / Samsung / Micron 主动缩减 DDR4/利基产能，资源向 HBM 与高端 DDR5 倾斜。
      • A股 重点 长鑫绑定 兆易创新（603986） Nor Flash + 利基 DRAM 设计；与长鑫协同填补海外退出留下的利基供给空洞。
      • A股 分销 香农芯创（300475） 存储分销龙头，涨价周期中库存收益与周转弹性大；Q1 利润高增（年报口径）。
    • 内存接口 / CXL 服务器 CPU 配套
      • Rambus DDR5 RCD/DB 专利授权与芯片。
      • A股 重点 年报 澜起科技（688008） DDR5 寄存时钟驱动器（RCD）全球领先；PCIe Retimer 与 CXL 内存扩展芯片受益 AI 服务器内存墙。
  • 3. NAND Flash / 企业级 SSD AI 数据湖与 Checkpoint
    • NAND 晶圆原厂 SSD BOM 约 60%-75%
      • Samsung / SK hynix / Kioxia / Micron / Solidigm 2026 主动减产 NAND 晶圆；QLC 高堆叠（200 层+）竞争加剧。
      • 产业地位 长江存储（未上市） 294 层 3D NAND 量产，全球份额约 16%；IPO 筹备中，三期扩产。
    • SSD 主控 / 模组 SSD BOM 约 10%-20%
      • Phison（群联）/ Silicon Motion（慧荣） 企业级 PCIe Gen5/Gen6 主控；AI SSD 需高 DWPD（每日全盘写入次数）耐久。
      • A股 重点 模组 佰维存储（688525） 嵌入式 + 企业级 SSD 模组；AI 端侧与数据中心双线布局。
      • A股 重点 模组 江波龙（301308） FORESEE 企业级 SSD + Lexar 品牌；收购 ZST 强化企业级存储。
  • 4. 设备 / 材料（间接层） CAPEX 周期受益
    • 刻蚀 / 沉积 / 检测：Lam Research、Applied Materials、KLA、TEL（东京电子）、ASML（DUV/EUV 部分 DRAM 层）
    • A股 中微公司 / 北方华创 / 拓荆科技 国产 DRAM/NAND 产线扩产带动设备订单；存储 CAPEX 回升周期受益。
    • A股 鼎龙股份 / 安集科技 CMP（化学机械抛光）材料、光刻胶等存储产线耗材。

投资机会与跟踪优先级

  1. 第一优先级 · HBM / 内存接口：SK 海力士、美光（海外）；A 股看澜起科技（DDR5/CXL 接口芯片，AI 服务器内存墙直接受益）。逻辑：HBM 产能售罄 + Rubin 内存 BOM 跃升；验证度高但 A 股估值已大幅透支。
  2. 第一优先级 · 利基 DRAM / 国产替代：兆易创新 + 未上市长鑫存储产业链（设备/材料）。逻辑：海外原厂主动退出利基市场，供给空洞 + 涨价弹性；长鑫 IPO 是板块催化剂。
  3. 弹性标的 · NAND 模组：佰维存储、江波龙（高 Beta，2026 Q1 业绩拐点已现；模组无晶圆议价权，周期下行风险高）。
  4. 预期差 · 企业级 SSD Gen6：市场仍按「周期股」定价部分模组厂，但 AI Checkpoint / 数据湖需求可能带来企业级 SSD 结构性增量；关注美光 9650 放量与国内企业级认证进度。
  5. 谨慎 / 回避：① 纯消费级存储模组（价格战敏感）；② 估值已反映 2-3 年涨价预期且 PE > 100 的标的；③ 无技术壁垒的纯分销在周期顶部的库存风险；④ 短期难兑现 HBM 收入的国产 DRAM 概念炒作。
