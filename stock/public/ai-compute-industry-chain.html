  • 塔尖（L0-L1）：应用与软件——决定 Token 需求总量与算力调用形态（训练 vs 推理 vs Agent）。

产业链金字塔 · 无序列表全拆解

  • L0 · AI 算力产业链总览 智算中心 TCO 100%
    • 应用与软件层 塔尖 约 3%-8% TCO（运营侧）：大模型 API、Agent、行业 SaaS；决定 Token 调用曲线。
    • 智算服务与运营层 约 5%-12%：公有云 GPU、智算中心租赁、算力调度平台。
    • 系统与集群层 约 8%-15%：AI 服务器、存储阵列、集群网络、机房集成。
    • 高速互连与板级层 约 6%-12%：光模块、交换机、NIC/DPU、高速 PCB/载板、铜连接。
    • 算力芯片与存储层 约 55%-70%：GPU/NPU/CPU + HBM + DDR + SSD；产业链最大价值池。
    • 散热与电源层 约 4%-10%：PSU、液冷、CDU、柴发/燃机备用。
    • 数据中心土建与机柜层 约 8%-15%：AIDC 土建、机电、机柜、布线、消防。
    • 能源与电网层 约 5%-12%（全生命周期）：市电接入、变电站、绿电、储能、算电协同。
    • 半导体制造与材料层 塔基 摊入芯片/板卡成本：晶圆代工、设备、EDA、特气、靶材、硅片。
  • L1 · 应用层（塔尖） Token 需求源头
    • 通用大模型与 API 服务
      • OpenAI / Anthropic / Google：GPT、Claude、Gemini 驱动全球云端训练与推理 Capex。塔尖定价者，决定 GPU 代际需求节奏。
      • 字节 / 阿里 / 腾讯 / 百度：国内云厂商资本开支与自研芯片/昇腾适配。国产算力最大下游买家。
      • A股 产业链相关 科大讯飞、金山办公、同花顺：行业大模型与 AI 应用落地。应用层弹性标的，算力成本为 Opex。
    • AI Agent 与编程助手
      • Cursor、Devin、Copilot 等提升长上下文推理与多步 Agent调用频次。
      • 推理算力占比提升 → 利好能效比更高的 ASIC 与国产 NPU；KV Cache 放大存储需求。
    • 行业垂直 AI
      • 自动驾驶：车载 AI 芯片、边缘推理；英伟达 Orin/Thor、特斯拉 FSD、地平线等。
      • 医疗 / 金融 / 政务：国产算力优先场景；昇腾+DeepSeek 等组合批量落地。
      • 具身智能 / 机器人：端侧 NPU + 云端训练；算力需求分散化。
      • AIGC 内容生成：视频/3D 生成推高多模态算力与存储带宽需求。
    • 端侧 AI（Edge AI）
      • AI PC / AI 手机：NPU、LPDDR、小模型本地推理；与云端算力互补。
      • AI 眼镜 / IoT：低功耗 SoC、传感器；算力链路与数据中心间接相关。
  • L2 · AI 软件栈 生态锁定层
    • 深度学习框架
      • PyTorch（Meta）：事实标准训练框架；CUDA 绑定深。
      • TensorFlow / JAX：Google 系；TPU 生态。
      • PaddlePaddle / MindSpore：百度/华为国产框架；昇腾 CANN 适配。
    • GPU 编程与驱动
      • CUDA（NVIDIA）：最大护城河；cuDNN、NCCL、TensorRT 全栈。
      • ROCm（AMD）：开源替代路径；MI300 生态建设中。
      • CANN（华为）：昇腾专用；已支持 DeepSeek、Llama 等主流模型。
      • oneAPI / SYCL（Intel）：XPU 统一编程。
    • 推理引擎与编译器
      • TensorRT、vLLM、Triton Inference Server、ONNX Runtime。
      • 国产：飞桨推理引擎、昇思 MindSpore Lite、寒武纪 MagicMind。
      • 推理优化决定同等芯片下的 Token 吞吐，影响客户芯片选型。
    • MLOps 与算力调度
      • Kubernetes + GPU 虚拟化（HAMi vGPU、MIG）；提升集群利用率。
      • Weights & Biases、MLflow；训练任务编排与实验管理。
