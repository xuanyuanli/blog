H200 整机成本产业链拆解

本页以 8 卡 H200 服务器为对象，从成本角度拆解整机、GPU（图形处理器）模块、HBM（高带宽存储器）、CoWoS（Chip-on-Wafer-on-Substrate，晶圆上芯片再上基板的 2.5D 先进封装）、PCB（印制电路板）、网络、电源散热等环节。由于 NVIDIA（英伟达）和 OEM（原始设备制造商）不披露逐项 BOM（物料清单），下方比例采用公开报价、官方规格、供应商公告和产业研究资料交叉后的区间表达。

数据与信源规则

  • 所有供应链判断以最新可得数据为准，并在页面标注当前更新时间；过期信息不作为核心结论依据。

  • A 股公司只有在具备权威资料支撑，或在对应环节与 NVIDIA AI 服务器链条有明确高相关性时才列入；无法确认进入 NVIDIA 产业链的公司不写入本报告。

阅读口径

  • “整机价值占比”按客户采购一台 8 卡 H200 服务器的硬件价值分布理解，不等同于 NVIDIA 制造成本。
  • “GPU（图形处理器）模块制造成本占比”只用于拆 H200 SXM（NVIDIA 服务器 GPU 模组形态）本身的成本结构，和最终市场售价差异很大。
  • EDA（电子设计自动化）、设备、材料不一定出现在单台服务器 BOM（物料清单）上，但会通过晶圆、封装、载板和 PCB（印制电路板）价格进入最终成本。
  • 涉及 A 股公司时，优先列已被权威资料支撑或具备明确高相关卡位的公司；仅有市场传闻、媒体猜测或无法验证的“进入 NVIDIA 产业链”说法不纳入。

    • GPU（图形处理器）加速子系统 约 75%-85% / 约 18-31 万美元：8 颗 H200 SXM、HBM3e（第三代增强型高带宽存储器）、CoWoS-S（硅中介层版 CoWoS，即晶圆上芯片再上基板的 2.5D 封装）、ABF（味之素堆积膜）载板、SXM 模块、NVSwitch（英伟达高速互连交换芯片）、HGX baseboard（HGX GPU 底板）、局部供电和热材料。它决定整机价格、交付周期和利润分配。
    • 主机平台 约 6%-10% / 约 1.5-3.5 万美元：双路 CPU（中央处理器）、2TB DDR5（第五代双倍数据率内存）、30TB NVMe（非易失性内存主机控制器接口规范）存储、服务器主板、BMC（基板管理控制器）、PCIe retimer（PCIe 信号重定时器）、电源管理 IC（集成电路）和机箱背板。
    • 网络互连 约 5%-10% / 约 1.2-3.5 万美元：10 张 ConnectX-7 400G NIC（网络接口卡）、线缆、光模块和交换机端口分摊。单机占比不如 GPU，但集群 TCO（总拥有成本）中权重会放大。
    • 电源、散热、结构件 约 4%-8% / 约 1-3 万美元：6 个 3.3kW PSU（电源供应器）、高风量风扇、散热器、风道、机箱、电源背板和机柜配套。
    • 整机集成、测试、保修、渠道和软件 约 5%-12%：老化测试、系统验证、售后服务、库存和交付风险。不同报价差异很大，往往来自这里和 GPU 供需溢价。

      • Quanta / QCT（广达 / 云达科技）：全球云服务器 ODM（原始设计制造商）龙头。卡位在大型云客户定制服务器和高密度 GPU 系统制造。
      • Wiwynn（纬颖）：云数据中心服务器 ODM 龙头之一。擅长 hyperscale（超大规模云）客户的定制化设计和快速量产。

  • 2. GPU（图形处理器）加速模块 整机约 75%-85%
    • H200 SXM（服务器 GPU 模组形态）与平台控制权 整机最大价值池
      • NVIDIA（英伟达）：H200 SXM、NVLink（英伟达 GPU 高速互连）/NVSwitch（英伟达高速互连交换芯片）和 CUDA（英伟达并行计算平台）生态的唯一平台方。H200 价格不是由硅片成本单独决定，而由算力稀缺、软件生态、互连能力和客户迁移成本共同决定。
    • EDA（电子设计自动化）、仿真和验证 不进单台 BOM（物料清单）；摊入 GPU 溢价
      • Synopsys（新思科技）：全球 EDA 双寡头之一，覆盖逻辑综合、验证、时序、DFT（可测试性设计）和大量接口 IP（知识产权核）。大 GPU 设计复杂度极高，工具链决定功耗、面积、时序能否收敛。
      • Cadence（楷登电子）：数字后端、模拟混合信号、封装协同设计和仿真强势。H200 这类产品要同时处理芯片、封装、SI（信号完整性）和 PI（电源完整性）。
      • Siemens EDA（西门子 EDA）：Calibre 物理验证和 Mentor（明导）系工具是先进制程签核关键环节。先进节点流片前的 DRC（设计规则检查）/LVS（版图与原理图一致性检查）/DFM（面向制造的设计）签核决定能否进入 TSMC（台积电）量产流程。
      • Ansys（安似科技）：电源完整性、热仿真和多物理场仿真龙头。H200 功耗和封装密度高，IR drop（电压降）、热热点和电迁移会影响频率、良率和寿命。
    • GPU Die（图形处理器裸片）晶圆制造 GPU 模块制造成本约 8%-15%；整机约 2%-5%
      • TSMC（台积电）：Hopper（NVIDIA Hopper GPU 架构代号，H100/H200 所属架构）GPU 使用 NVIDIA 定制的 TSMC 4N 工艺。同时掌握先进逻辑制造和 CoWoS（Chip-on-Wafer-on-Substrate，晶圆上芯片再上基板的 2.5D 先进封装），是 H200 量产交付的核心瓶颈之一。
      • ASML（阿斯麦）：EUV（极紫外光刻）/DUV（深紫外光刻）设备核心供应商。先进逻辑产能扩张离不开 ASML，成本最终体现在 TSMC 晶圆价格里。
      • Applied Materials（应用材料）：沉积、刻蚀、离子注入、CMP（化学机械抛光）等设备覆盖面最广。先进逻辑和先进封装都依赖其设备。
      • Lam Research（泛林集团）：刻蚀和沉积设备强势。先进制程多层结构和 HBM（高带宽存储器）/封装相关工艺需要高一致性刻蚀沉积能力。
      • KLA（科磊）：缺陷检测和量测龙头。H200 逻辑 Die 面积大，良率对成本极敏感。
    • HBM3e（第三代增强型高带宽存储器）存储 GPU 模块制造成本约 35%-45%；H200 最大增量
      • SK hynix（SK 海力士）：HBM 龙头，率先量产 HBM3e。HBM 是 H200 的性能和成本核心，SK hynix 在堆叠、TSV（硅通孔）、热管理和 NVIDIA 认证上领先。
      • Micron（美光科技）：官方宣布 24GB 8H（8 层堆叠）HBM3e 量产并用于 NVIDIA H200。Micron 是 H200 HBM3e 供应多元化的关键，公开资料中与 H200 绑定最明确。
      • Samsung Electronics（三星电子）：全球 DRAM（动态随机存取存储器）龙头和 HBM 重要追赶者。即使 HBM3e 节奏相对慢，三星仍是 HBM 供给扩张和价格竞争的重要变量。
      • Advantest（爱德万测试）：高端存储和 SoC（系统级芯片）测试设备龙头。HBM 需要 KGD（已知合格裸片）测试，测试良率直接影响可用于 CoWoS 的合格堆叠数量。
      • DISCO（迪思科）：晶圆切割、减薄和研磨设备龙头。HBM 堆叠需要薄晶圆处理，是 TSV/HBM 制程中的关键设备商。
    • CoWoS-S（硅中介层版 CoWoS，晶圆上芯片再上基板的 2.5D 先进封装）和硅中介层 GPU 模块制造成本约 20%-30%
      • TSMC（台积电）：H200 所在 Hopper（NVIDIA Hopper GPU 架构代号）代际主要依赖 CoWoS-S。CoWoS 把 GPU Die（裸片）和多颗 HBM（高带宽存储器）放到同一封装中，是 H200 高带宽的物理基础。
      • BESI（贝思半导体）：先进封装键合设备龙头。键合精度和吞吐影响先进封装良率。
      • ASMPT（ASM 太平洋科技）：封装设备大厂，覆盖贴装、键合、互连等环节。先进封装扩产离不开封装设备供应。
      • Resonac（力森诺科）：半导体封装材料大厂。底填、模塑等材料影响翘曲、可靠性和散热。
    • ABF（味之素堆积膜）载板、SXM 模块和热材料 GPU 模块制造成本约 5%-10%
      • Ibiden（揖斐电）：高端 ABF 载板龙头。大尺寸 GPU 封装载板对层数、线宽线距和翘曲控制要求极高。
      • Shinko Electric（新光电气工业）：高端封装载板和半导体封装大厂。在 CPU/GPU 高端载板中卡位深，客户认证壁垒高。
      • Unimicron 欣兴：台系 IC 载板和高阶 PCB 龙头。同时覆盖 ABF 载板和高端 PCB，是 AI 服务器板级价值提升的重要受益者。
      • Ajinomoto（味之素）：ABF 膜关键供应商。ABF 载板以 Ajinomoto Build-up Film（味之素堆积膜）命名，其材料供应决定高端载板扩产能力。
      • Henkel（汉高）：热界面材料、胶黏剂和封装材料大厂。H200 功耗高，TIM（热界面材料）、导热胶和结构胶影响散热效率和长期可靠性。
    • NVSwitch（英伟达高速互连交换芯片）、HGX baseboard（HGX GPU 底板）和高速连接 整机约 3%-8%
      • NVIDIA（英伟达）：DGX H200 官方披露 4 个 NVSwitch，提供 7.2TB/s 双向 GPU-to-GPU 带宽。NVSwitch 把 8 颗 H200 组织成统一高带宽加速域，是 HGX 与普通多卡服务器的关键差异。
      • Amphenol（安费诺）：高速连接器全球龙头。GPU 服务器内部高速信号和高电流连接对 SI/PI（信号完整性/电源完整性）要求极高。
      • TE Connectivity（泰科电子）：连接器和传感器大厂。在服务器、网络设备和电源连接中覆盖广。
      • Molex（莫仕）：高速连接器、线缆和背板互连供应商。AI 服务器高速互连和内部布线密度提升，Molex 受益于高速连接升级。
      • A股 间接核验 沃尔核材：公司高速通信线产品用于 DAC/AEC 等铜连接方案，公开口径显示客户包括安费诺、莫仕、泰科等国际连接器厂。更稳妥的表述是通过连接器/线缆组件客户间接参与 NVIDIA GB200/后续机柜级高速铜连接链；未见公司直接披露 NVIDIA 订单，因此不写成直接供货。
  • 3. PCB（印制电路板）产业链 整机约 2%-5%；高层数、低损耗材料决定弹性
    • HGX baseboard / GPU tray（HGX GPU 底板 / GPU 托盘）与板级价值核心 单机 PCB 价值最高
      • NVIDIA（英伟达）：通过 HGX H200 参考架构定义 GPU tray、NVSwitch、SXM 模块、高速连接和供电布局。PCB 价值不是普通服务器板平均放大，而是被 8 颗 H200、4 个 NVSwitch、高电流供电和高速互连集中推高。
      • 价值排序小结 GPU tray 最高，其次主板，再到网卡/背板/控制板：H200 的 PCB 钱主要花在 HGX baseboard/GPU tray 和高速服务器主板上。判断 PCB 公司是否真正受益，要看它能否做高层数、低损耗、高速服务器板，而不是只看是否有普通服务器 PCB 产能。
    • PCB 设计、SI/PI（信号完整性 / 电源完整性）仿真和验证 不单独进 BOM（物料清单）；决定可制造性和认证周期
      • Cadence（楷登电子）：高速 PCB、封装协同设计和 SI/PI 仿真工具强势。H200 板级设计要同时处理 PCIe、NVLink、SerDes、高电流供电和散热约束，前期仿真直接影响改板次数。
      • Synopsys（新思科技）：覆盖芯片、封装和系统级验证工具。GPU、封装载板和 PCB 的协同验证越重要，EDA 工具链对系统成本和交付节奏的影响越大。
      • Ansys（安似科技）：电磁、电源完整性、热和结构仿真龙头。高功耗 GPU 服务器容易受 IR drop（电压降）、串扰、损耗和热点影响，仿真能力决定板级可靠性。
    • 高价值板卡：GPU 底板、服务器主板、高速网卡板和背板 说明整机 PCB 钱花在哪些板卡上
      • HGX baseboard / GPU tray（HGX GPU 底板 / GPU 托盘） 单机 PCB 价值最高：承载或连接 8 颗 H200 SXM、4 个 NVSwitch、GPU 供电、高速信号走线和管理控制。这是 H200 整机里 PCB 难度和价值量最高的区域，要求高层数、低损耗材料、严格阻抗控制、高电流供电和高可靠性。
      • 服务器主板 / CPU motherboard（主机主板） 面积大、层数高、验证复杂：连接双路 CPU（中央处理器）、DDR5（第五代双倍数据率内存）、PCIe（高速串行计算机扩展总线）、BMC（基板管理控制器）、NVMe 存储和管理接口。它的单板难度通常低于 GPU tray，但面积大、接口多、可靠性和固件验证复杂，是主机平台成本的重要组成。
      • 高速网卡板 / OCP NIC 板（开放计算项目网卡板） 随 400G/800G 网络升级提高：承载 ConnectX-7 NIC（网络接口卡）、高速 SerDes（串并转换高速接口）、供电和散热结构。单板价值小于 GPU tray，但 400G/800G 速率提升后，对低损耗 PCB、连接器和信号完整性的要求明显提高。
      • NVMe 背板、电源背板、风扇/管理控制板 数量多，单板价值较低：负责 SSD（固态硬盘）连接、电源分配、风扇控制、BMC 管理信号和机箱内部互连。这些板卡不是最高价值环节，但 H200 高功耗和高密度设计会抬升它们的可靠性、散热和供电要求。
    • 高多层板和 HDI（高密度互连）制造 PCB 成本主体：加工、材料损耗和良率
      • Unimicron 欣兴：台系高端 PCB/IC 载板龙头。核心在 AI 服务器高层数板、HDI 和载板能力，既吃 PCB 价值提升，也参与封装载板升级。
