Vera Rubin 机架成本产业链拆解

本页基于摩根士丹利（Morgan Stanley）2026 年 5 月 21 日对 NVIDIA（英伟达）下一代 Vera Rubin VR200 NVL72 机架的 bottom-up BOM（物料清单）拆解，梳理单机架约 780 万美元 的成本结构、相对 GB300 的代际变化，以及 PCB（印制电路板）、MLCC（多层陶瓷电容）、ABF（味之素堆积膜）载板、内存、液冷等环节的投资映射。

四锚点摘要

  • 行业：AI 数据中心机架级加速计算（Rubin 代际，2026H2 起量）
  • 论文/研报：Morgan Stanley《Rubin VR200 BOM Teardown》（Howard Kao 团队，2026-05-21）
  • 热点：GPU 不再「独吞」BOM；内存占比升至 26%；PCB/MLCC 价值翻数倍
  • 产业链：72×Rubin GPU + 36×Vera CPU + HBM4/LPDDR5X/3D NAND + 全液冷 Oberon 机箱

ODM 采购价（大摩估算）

约 780 万美元/柜

GB300 约 399 万美元，代际增幅约 +95%。经 OEM 采购更高；云厂自采内存可降至约 670 万美元。

最大成本池变化

GPU 仍第一，内存跃升第二

GPU 约 396 万（51%），较 GB300 +57%；内存约 200 万（26%），+435%。

Rubin 平台规格（公开口径）

20.7TB HBM4 + 54TB LPDDR5X

72 GPU × 288GB HBM4；36 CPU × 1.5TB LPDDR5X；首次大规模集成 3D NAND。

零部件涨幅冠军

PCB +233%

MLCC +182%、ABF +82%、NVLink 芯片 +122%；液冷仅 +12% 但变为全液冷必选。

阅读口径

  • 大摩数据来自 ODM 侧 bottom-up BOM 估算，不等于 NVIDIA 官方 BOM 或终端客户成交价。
  • 「机架价值占比」按 hyperscaler 从 ODM 采购一台 VR200 NVL72 理解；GPU/内存单价含平台溢价与供需因素。
  • 若云厂商绕过 NVIDIA 直接采购 SOCAMM/LPDDR5X 与 HBM，机架价可少约 110 万美元——这会重塑利润分配。
  • A 股映射按产业链高相关 + 公开披露交叉验证；无权威证据的不写「确定供货 Rubin」。

研报核心结论：算力价值从「GPU 独大」向全链扩散

Morgan Stanley · Howard Kao · 2026-05-21 · 二手摘要交叉自公开财经媒体与社区转述

  • 设计哲学：Rubin 强调「内存优先」——用海量 HBM4、LPDDR5X 与 3D NAND 喂饱算力，降低 GPU 等数据瓶颈。
  • 结构巨变：GPU BOM 占比从 GB200 约 65% 降至 VR200 约 51%，但 GPU 绝对值仍从约 252 万增至约 396 万美元。
  • ODM 悖论：市场担心 Rubin 托盘「标准化」压缩 ODM 附加值；大摩测算 ODM value-add 从约 10.8 万增至约 15.0 万美元（+35%～40%），但毛利率从 2.7% 降至约 1.9%。
  • 寄售模式：鸿海 2025Q4、广达 2026Q1 法说提及 consignment——客户自采核心料、ODM 只组装，减轻营运资金压力，亦可能压缩 ODM 营收规模。
  • 量产节奏：Vera Rubin 预计 2026Q3 首批出货，Q4 放量；Rubin Ultra 计划 2027H2，将大规模采用 800V DC 供电。

产业链与成本树

  • 0. 成本总览 机架 100% ≈ 780 万美元
    • GPU 加速子系统 约 51% / ~396 万美元：72 颗 Rubin GPU，单颗约 5.5 万美元；含 CoWoS、HBM4 堆叠、Rubin 模组与 NVLink 域。
    • 内存与存储 约 26% / ~200 万美元：HBM4 ~40-50 万 + LPDDR5X ~44-54 万 + 3D NAND ~100 万（GB300 近零）。
    • 板级与被动元件 约 2% / ~14 万美元：PCB ~11.7 万 + MLCC ~0.43 万 + ABF ~2.0 万；代际弹性最大集群。
    • 互连与网络芯片 约 2% / ~14 万美元+：NVLink Switch 18→36 颗，ConnectX 36→72 颗；网络芯片价值约 +121%。
    • 电源与液冷 约 2% / ~15 万美元：110kW 电源标配；全液冷无风扇，~7.2 万/柜。
    • CPU、机架集成与其余 约 17% / ~130 万美元+：Vera CPU ~18 万（持平）；ODM 组装测试 value-add ~15 万；含 Oberon 机箱、线缆、光模块等。
  • 1. 内存：从配角到第二成本项 +435% · ~200 万美元
    • HBM4（高带宽存储器第四代） 约 40-50 万美元
      • SK hynix（SK 海力士）：HBM 龙头，HBM4 产能与认证进度领先。供应极紧，掌握定价权；Micron 已宣布 HBM4 36GB 12H 于 2026Q1 量产并面向 Vera Rubin。
      • Micron（美光科技） 官方公告：HBM4 量产出货 Rubin 平台。美股最直接受益标的之一。
      • Samsung（三星电子）：HBM 追赶者，供给多元化变量。
    • LPDDR5X 约 44-54 万美元 · 54TB：SemiAnalysis 口径约 $8/GB 起，涨价至 $10/GB 则成本更高。容量为 GB200 的 3 倍以上，SOCAMM 模组形态。
    • 3D NAND 约 100 万美元：Rubin 首次大规模集成，用于模型加载与 checkpoint。纯增量环节，GB300 几乎为零。
    • 关键变量：云厂 direct source 内存 → 机架价可降至 ~670 万美元，NVIDIA 内存加价环节受冲击。
  • 2. PCB：增幅最大的下游环节 +233% · ~11.7 万美元
    • 纯增量 PCB（GB300 不存在） ~4.6 万美元
      • ConnectX 模组 PCB：72 块 × ~270 美元 ≈ 1.94 万
      • 中板 PCB：18 块 × ~1500 美元 ≈ 2.7 万
    • 升级项：计算板 22→26 层 HDI，CCL M7→M8；交换机托盘 24→32 层；新增 44 层中板。
    • Unimicron 欣兴 大摩五大组件：台系 AI 服务器 PCB/载板龙头。
    • ZDT 臻鼎 大摩五大组件：高端 PCB 与模组板受益。
    • A股 重点 高置信 胜宏科技：AI 服务器 PCB 核心供应商口径。Rubin 层数与模组增加直接推高 value content。
    • A股 重点 客户保密 沪电股份：高速运算服务器 PCB，具体客户不披露。
    • A股 互动平台 景旺电子：NVIDIA 合格供应商名单内批量供货。
    • A股 产业链 生益科技：高速 CCL（覆铜板）材料升级 M7→M8 受益。
  • 3. MLCC + ABF：「隐形」与高门槛底座 MLCC +182% · ABF +82%
    • MLCC ~43 万美元/柜 · ~60 万颗：计算板 25→90 美元/板；交换机板 20→45 美元/板；BlueField DPU + ConnectX 新模组增量。大摩称 ODM 正积极囤货；需求「异常旺盛」。
    • Murata（村田）、TDK、Samsung Electro-Mechanics：全球高端 MLCC 主力。
    • A股 结构性受益 三环集团、风华高科：国内 MLCC 龙头，AI 服务器增量逻辑，但高端仍以日韩为主。
    • ABF 载板 ~2.0 万美元：Rubin GPU 载板单价 ~200 美元 vs Blackwell ~100 美元；NVSwitch/ConnectX 数量翻倍。
    • Ibiden（揖斐电）、Shinko（新光电气）、Unimicron 欣兴：高端 ABF 载板主力。
    • A股 国产替代 兴森科技、深南电路：ABF/封装基板长期窗口，Rubin 直接占比待验证。
  • 4. GPU、互连与平台 GPU ~396 万 · NVLink +122%
    • NVIDIA（英伟达）：Rubin GPU、NVLink Switch、ConnectX、BlueField、CUDA 生态平台方。仍捕获最大价值池，但 BOM 占比下降。
    • TSMC（台积电）：Rubin 逻辑代工 + CoWoS 先进封装。产能与交期仍是硬瓶颈。
    • NVLink Switch ~6.5 万 → ~14.4 万：芯片数量 18→36 颗。
  • 5. 电源、液冷与 ODM 集成 电源 +32% · 液冷 +12%
    • 电源 ~7.6 万美元：标配 110kW 电源机架；至少一家美国云厂已采用 HVDC 独立电源机架；2027H2 Rubin Ultra 大规模 800V DC。
    • Delta 台达电 大摩/供应链：与至少 3 家美国 hyperscaler 推进 HVDC，2026H2 小批量。
    • 液冷 ~7.2 万美元：Vera Rubin 全液冷、无风扇；增量来自 tray 歧管、QD（快速接头）与冷板优化。
    • Auras 奇鋐 大摩五大组件：散热模组龙头。
    • A股 重点 液冷链 英维克、高澜股份：全液冷标配化受益，具体 Rubin 份额待披露。
    • ODM 集成 value-add ~15 万美元 · 毛利率 ~1.9%
      • Wiwynn 纬颖 大摩首选： hyperscale ODM 龙头。
      • Wistron 纬创、Quanta 广达、Foxconn 鸿海：AI 服务器 ODM 主力；寄售模式先行者。
      • A股 重点 NVIDIA/Foxconn 工业富联：Foxconn 体系 AI 服务器制造与高速连接。

投资机会与跟踪优先级

  1. 第一优先级 · 内存/HBM4：BOM +435%，供给最紧。SK hynix、Micron、Samsung；国内看 HBM 封装材料与设备窗口。
  2. 第一优先级 · PCB/CCL：+233% 为零部件涨幅冠军，且纯增量模组明确。胜宏、沪电、景旺、生益；台系欣兴、臻鼎。
  3. 第二优先级 · MLCC/ABF：用量与单价齐升；MLCC 看村田/TDK 与国产结构性机会；ABF 看 Ibiden/欣兴。
  4. 第二优先级 · 液冷+HVDC：Rubin 全液冷 + 110kW/800V 电源升级。台达电、奇鋐；A 股英维克、高澜。
  5. 预期差 · ODM：市场担心标准化压缩附加值，大摩认为 dollar value-add +35%～40%——关注纬颖、工业富联的绝对利润而非毛利率 alone。
  6. 谨慎：寄售模式扩散→ODM 营收规模与 NVIDIA 内存渠道利润；GPU BOM 占比下降≠ NVIDIA 失去定价权。
